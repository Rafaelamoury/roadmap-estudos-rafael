# Semana 1 - HTML e CSS

## Dia 1 - Estrutura básica do HTML

### Conteúdos estudados

-Como  uma página HTML é estruturada
-Declaração `DOCTYPE` 
-Tags `html´, `head´ e `body´
-Codificação UFT-8
-Título da aba do navegador 
-Título principal com `h1´
-Parágrafo com `p´
-Abertura e fechamento de tags

### Prática realizada

criei minha primeira  página  HTML para iniciar o portfólio pessoal.

### O que aprendi

O HTML organiza a estrutura  e o conteúdo  de uma página.
O `head´ contém informações sobre a página, enquanto o `body´ contém o conteúdo que aparece na tela.
